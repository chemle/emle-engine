emle._backends¶

The backends module containts classes for computing in-vacuo energies and gradients. This is an internal module. Backends are used by the emle.calculator and emle._analyzer modules.

class emle._backends._backend.Backend(charges=(0,), mults=(1,), states=(0,))[source]¶

Base class for in-vacuo backends.

This class should not be instantiated directly, but should be subclassed by specific backends.

The ‘charges’, ‘mults’ and ‘states’ attributes hold the QM charges, spin multiplicities and electronic states (0 is the ground state) that the model supports, as a tuple, or None for any value. The default is a neutral singlet in the ground state. Of the ‘qm_charge’, ‘mult’ and ‘state’ arguments, those that ‘calculate’ takes are passed to it, or all of them if it takes ‘**kwargs’.

Constructor.

Parameters:

  • charges (tuple of int) – The supported QM charges, or None for any value.

  • mults (tuple of int) – The supported spin multiplicities, or None for any value.

  • states (tuple of int) – The supported electronic states, or None for any value.

class emle._backends.AIMNet2(model='aimnet2', device=None)[source]¶

AIMNet2 in-vacuo backend implementation.

Constructor.

Parameters:

  • model (str) – The AIMNet2 model to use: a name from the aimnet model registry, e.g. “aimnet2” or “aimnet2-b973c”, or the path to a model file. If None, “aimnet2” is used. Spin multiplicities other than 1 need an open-shell model, e.g. “aimnet2-nse”.

  • device (str) – The device to run the model on, e.g. “cpu” or “cuda”. If None, CUDA is used when available.

class emle._backends.OMNIP2x(model=None, device=None)[source]¶

OMNI-P2x in-vacuo backend implementation.

Constructor.

Parameters:

  • model (str, list of str) – Path(s) to OMNI-P2x model files, e.g. fine-tuned models saved by MLatom. The energy is averaged over the models. If None, the official OMNI-P2x models are downloaded on first use.
